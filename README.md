# FORMA HOME Design Private

**Дизайнерский каталог мебели FORMA HOME.** Репозиторий: `gkkm8bm7rn-eng/forma-designer-private`.

Этот проект **отдельный от оптового сайта TETOpt**. Изменения и релизы здесь не затрагивают репозиторий `tetopt`.

## Структура проекта

```text
index.html                     Разметка магазина, подключение CSS/JS
styles.css                     Базовая структура и стили
enhancements.css               Дополнительные визуальные и загрузочные состояния
axes.css                       Раздельный выбор материалов и цветов
ui.css                         Карточки, диалоги, адаптивная вёрстка
architectural-minimal.css      Совместимость существующей визуальной системы
designer-approved-release.css  Утверждённый «Жемчужный лён»: CSS релиза
media-policy.js                Политика фотографий и резервные загрузки
variants.js                    Варианты товара, цветовые кружочки, цены, галерея
app.js                         Каталог, фильтры, карточки, история, избранное, корзина
search-fallback.js             Запасной путь поиска
cart-feedback.js               Счётчики и управление количеством в корзине
sw.js                          Service Worker, офлайн-кэш оболочки и фото
data/catalog-index.json        Список моделей и вариантов (актуальные цены)
data/category-assignments.json Категории и фильтры
data/details/*.json            Детали и дополнительные фото, загрузка по требованию
assets/products/               Фотографии товаров
scripts/                       Проверки данных и iPhone WebKit
.github/workflows/             Автоматизированные проверки pull request
```

## Источники данных и безопасность изменений

В `main` сохранён актуальный `data/catalog-index.json`. На момент выпуска он содержит **586 моделей и 1429 исходных вариантов**; пользовательский каталог исключает 3 служебных/непубликуемых варианта. Фотографии находятся в `assets/products/`. При выборе конкретного варианта ключом служит `sourceId`, а не похожее название товара.

При открытии полной карточки `app.js` подгружает соответствующий файл `data/details/` и дополняет его подтверждёнными ценовыми полями выбранного варианта из `catalog-index.json` (функция `withCatalogPrices`). Для дизайнерского релиза массивы цен и товарные данные не переписываются.

## Утверждённый интерфейс

- Цвета: **жемчуг `#F0EDE9`**, **лён `#E7E2DC`**, **фарфоровый туман `#E8E9E7`**, молочный `#F4F0EB`, тауп `#DDD8D2`, графит `#3D4246`.
- Текстовые блоки карточек — молочные; область вокруг фотографий — белая, сами изображения не редактируются.
- Блок с ценой и кнопкой покупки прижимается к низу карточки без обрезания длинного названия.
- Цветовые кружки: 22 px видимого диаметра, 30 × 30 px зона нажатия, 6 px между столбцами и 8 px между рядами, максимум 4 × 2; на очень узких экранах 3 × 2. Индикатор `+N` открывает полный выбор.
- Обивка и каркас выбираются независимо; несовместимые комбинации не синтезируются.
- Утверждённая нежирная типографика сохраняется; оригинальный логотип — исключение.

`designer-approved-release.css` собран в **единственный релизный CSS-файл** из утверждённых пробных стилей в их исходном порядке. Это гарантирует совместимость внешнего вида на момент переноса и уменьшает число отдельных CSS-запросов. В дальнейшем повторяющиеся переопределения можно аккуратно рефакторить только после нового визуального сравнения; сами архивные пробные ветки остаются для отката и сравнения.

## Кэш, публикация и проверки

Страницы и скрипты версионированы одной строкой `SHELL_VERSION` в `sw.js`, включая CSS релиза. Кэш фотографий версионируется **отдельно** и не сбрасывается при изменении дизайна.

При pull request в `main` запускается `.github/workflows/mobile-storefront-reliability.yml`: статические проверки, синтаксис JavaScript, а также WebKit-тесты iPhone (загрузка каталога, фото, прокрутка, выбор категории, управление количеством товара и цветовые кружки при 320–430 px).

**Правило релиза:** изменения интерфейса сначала проходят отдельную пробную ветку, затем тесты pull request; менять товарные JSON, цены или изображения без явной отдельной задачи нельзя.
